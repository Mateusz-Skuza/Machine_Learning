# Machine_Learning

This repository contains a set of projects focused on applying artificial intelligence to classification and strategic gaming. It ranges deep learning and game strategy algorithms.

## CNN Optimization (CIFAR-10)
This project tests how different settings affect the performance of an image recognition network (CNN) using the **CIFAR-10** dataset. The study compares four model variants to see which one learns fastest and most accurately:

* **Base Model**
* **Batch Normalization**
* **Dropout**
* **Combined Approach**

## Unbeatable Tic-Tac-Toe AI
A Python implementation of Tic-Tac-Toe featuring an unbeatable computer opponent. The AI uses **Minimax** and **Alpha-Beta Pruning** algorithms to always choose the winning or drawing move by analyzing the entire game tree.

## RL Algorithms Optimization
This group project tests how different hyperparameters affect the peformance of Reinforcement Learning algorithms. The study compares four algorithms across various Gymnasium environments (Acrobot-v1, LunarLander-v3, CartPole-v1) to see which one learns most most stably and efficiently:

* **PPO**
* **DQN**
* **QRDQN**
* **REINFORCE**

The experiments track the impact of variables such as learning rate, batch size, gamma, buffer size and exploration fraction using Weights and Biases.
